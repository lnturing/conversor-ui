Sobre

    
Por que criamos esse conversor?

    
Nosso sistema foi desenvolvido para facilitar e agilizar a conversão de arquivos .ui, criados no Qt Designer, em código Python compatível com PyQt6.
A ferramenta permite transformar interfaces gráficas desenvolvidas pelo QtDesigner em código Python de forma rápida, prática e online facilitando a integração entre o design da interface e o desenvolvimento da aplicação.
O projeto foi pensado especialmente para estudantes e desenvolvedores que trabalham com Python e PyQt6, oferecendo uma solução mais simples, facilitando o processo.

Tutorial

    
Como converter seu .ui em 3 passos


    

      

        
1

        
Upload

        
Arraste até 10 arquivos .ui exportados do Qt Designer até a área tracejada, ou clique em "Selecionar arquivos".

      

      

        
2

        
Converter

        
O servidor converte cada arquivo e a página mostra a árvore de widgets e o código Python para PyQt6.

      

      

        
3

        
Download

        
Clique em "Baixar .py" (ou em "Baixar tudo (.zip)" se enviou vários). O arquivo já abre a janela ao ser executado.

      

    


    

      
Se ainda tiver dúvidas e/ou quiser entender melhor o passo a passo, clique em "Saiba mais" para baixar um tutorial completo, desde a escolha do arquivo até o download.
